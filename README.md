# Acervo — Catálogo de Colecionáveis

Sistema web para cadastro, organização e exibição de itens colecionáveis em um catálogo digital.

## Sobre o Projeto

O **Acervo** permite que colecionadores registrem seus itens com fotos, categorias e descrições, tornando-os acessíveis a visitantes e potenciais interessados por meio de buscas simples e intuitivas.

## Tecnologias

| Tecnologia | Função |
|---|---|
| HTML | Estrutura das páginas |
| CSS | Estilização e layout |
| Node.js | Lógica de servidor (back-end) |
| JWT | Autenticação stateless via tokens |
| GitHub | Controle de versão e colaboração |
| Swagger/OpenAPI | Documentação da API |
